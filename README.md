## 🚀 Overview

The **Smart Green Coal Generator Network** bridges clean-energy biomass production with modern IoT telematics. Traditional biomass charcoal/green-coal processing often suffers from inconsistent heat control, undetected gas leaks, and inefficient yield management. 

This project delivers a centralized web dashboard integrated with real-time sensor streams to track thermal degradation, gas emissions, and moisture levels, ensuring optimal bio-coal synthesis with minimal atmospheric impact.

---

## ✨ Key Features

- **📊 Real-Time Telemetry Dashboard:** Live data streaming for temperature, humidity, gas concentration (CO/CO2), and pyrolysis process status.
- **⚡ Dynamic Alerts & Threshold System:** Automated notifications when environmental or operating parameters breach safety thresholds.
- **🌐 Decentralized Node Tracking:** Monitor and manage multiple green coal generator units across geographic locations from a single interface.
- **📈 Historical Analytics:** Graphical trends for burn cycles, energy yield estimation, and carbon offset calculations.
- **🎨 Responsive UI:** Clean, modern interface built with Tailwind CSS for seamless viewing on desktop and mobile screens.

---

## 🛠️ Tech Stack

### **Frontend & Interface**
- **HTML5 & CSS3:** Semantic layout and web standards.
- **Tailwind CSS:** Modern utility-first styling for interactive dashboards.
- **JavaScript (ES6+):** Dynamic UI rendering and real-time data handling.

### **Backend & Data Storage**
- **Firebase Realtime Database / Firestore:** Low-latency sensor data synchronization and state storage.
- **Firebase Hosting / Auth:** Secure user authentication and cloud hosting.

### **IoT & Hardware Integration**
- Microcontrollers (ESP32 / ESP8266)
- Temperature Sensors (DHT22 / MAX6675 Thermocouple)
- Gas Sensors (MQ-Series for CO/CO2/Smoke)
